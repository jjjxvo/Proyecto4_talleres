# Proyecto4_talleres
Proyecto de Programación I – Administración de talleres con CSV

Este proyecto puede administrar talleres de la Semana de la Informática que puede gestionar cupos, inscribir participantes o desinscribir manteniendo una constancia en los datos mediante archivos CSV.

Este proyecto esta dividido en 3 partes, la primera es importar el csv para poder gestionar el guardado y carga de datos de los archivos CSV. La segunda parte son las funciones del sistema dónde el sistema tomará cada función única para que el código en si pueda funcionar correctamente. La tercera parte es el menú del código la cual su función es llamar a todas las funciones del sistema mientras se indique una opción.

Estructura:

1)Importar csv:
-Guardar los talleres y sus inscritos en un archivo csv.
-Cargar automaticamente los datos al iniciar el programa.

2)Funciones del sistema:
Gestión de talleres (CRUD)
-Crear talleres
-Actualizar cupos
-Eliminar talleres
-Listar todos los talleres
-Reportes
Gestión de participantes
-Inscribir participante
-Desinscribir participante

3)Menú del sistema:
-Se crea un menú para que el usuario permita elegir opciones que llaman a cada función del sistema y que gracias a esto el sistema es fácil de usar, comprender y navegar.

Ejecución del programa:
1) Descargar los archivos: Trabajos_Talleres.py y Talleres.csv
2) Ejecutar en la terminal: python Trabajo_Talleres.py
3) Usar el menú para utilizar las funciones del sistema
